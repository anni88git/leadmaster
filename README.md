# Lead Master Workspace

This workspace contains the **LeadManager** project, a minimal ASP.NET Core Web API (.NET 8) for managing sales leads.

## Projects

### [LeadManager](./LeadManager/)
A self-contained .NET 8 Web API demonstrating:
- Minimal APIs (5 CRUD operations)
- Entity Framework Core with SQL Server LocalDB
- Basic validation
- Swagger Integration

See the [LeadManager README](./LeadManager/README.md) for detailed instructions on how to run and test the application, including sample JSON requests and Postman configuration.
